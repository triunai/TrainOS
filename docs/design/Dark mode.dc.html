Dark mode
Light is the shipping theme; dark is a token swap on top of it. No component, layout, spacing or geometry changes between themes — every value below maps one-to-one, so integrating dark later means resolving the same token names against a second palette. Two screens are rendered below as proof — the executive dashboard and the collections queue — and section 03 links to the dark twin of every other screen in the pack.

Rules that survive the swap. Three colours only — ink neutrals, electric blue, charcoal/graphite. Blue budget stays 5–15%. AI is still a 6% blue tint plus ✦ and a label, never a solid fill. Status colour still lives on chips only. Shadows deepen rather than lighten (rgba(0,0,0,.55)) and elevation is carried by surface lightness, not by heavier borders.

Two things need care at integration. Text primary is #E8EBF0, not white, to reduce halation on the dark card; and the primary blue lifts from #1F5BFF to #4C82FF so that solid buttons keep 4.5:1 against their own surface, while the label on that button stays near-white in both themes — the accent never carries dark text. Status chip text lifts the same way — the fills go dark, the text goes light.
