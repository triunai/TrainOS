▸Annotation & handoff · M18-S01
Purpose
One place to see what every agent may do, what it costs, how well it scores and how to stop it.
Primary user
System Admin; MD approves autonomy promotions.
Components used
Page header, MetricStrip (6 cells), pill tabs, data table with per-action autonomy chips, toggle controls, warning banner.
Data contract
Agent{id,name,status,scopes[],costMonthRM,evalScore,lastRunAt,killSwitch} · AutonomyGrant{agentId,actionType,level,approverRole,thresholdRM}
Actions & policy gates
Kill switch per agent (immediate, audited), Register agent (primary), open autonomy ladder. Promotions are policy-gated to the MD.
States rendered
Knowledge Agent paused after an eval regression, with the reason stated and a resume condition.
AI & approval behaviour
This is the control surface for AI rather than an AI surface itself; no generated content, so no ✦ badges on rows.
Wired to
Agent → M18-S02 · Last run → M18-S04 · Approvals raised → M02-S01 · Evals → M18-S05.
Assumptions
Money-moving action types cannot be set to Autonomous; the ladder enforces Act-with-approval as the ceiling for send, book and invoice.

▸Annotation & handoff · M18-S04
Purpose
Show the orchestrator’s reasoning as a tree — who did what, on which model tier, at what cost, and exactly where policy stopped it.
Primary user
System Admin; approvers arrive here from an approval.
Components used
RecordHeader (5 metrics), run rail with failed variant, trace tree node, event rows, state-card panel, budget bars, tier chip, jury chip.
Data contract
AutomationRun{id,orchestrator,trigger,status,durationMs,cost,tokens,cacheHitRate,tiersUsed[]} · TraceNode{id,parentId,kind:"ORCHESTRATOR"|"SUB_AGENT"|"TOOL",name,tier,model,provider,tokens,cacheHitRate,cost,durationMs,status,haltedBy?} · RunEvent{type:"ESCALATION"|"JURY"|"TRUNCATION"|"HANDOFF"|"CHECKPOINT"|"POLICY_HALT",detail,at} · StateCard{goal,plan[],decisions[],constraints[],recordPointers[],openQuestions[],tokenBudget,costBudget}
Actions & policy gates
Replay in sandbox, Retry from checkpoint, Dismiss to dead-letter, Open approval (primary), download trace.
States rendered
Halted at policy with the jury result recorded; a failed run in the rail with a live checkpoint.
AI & approval behaviour
Every node names its tier, model, provider, cache-hit and cost. Escalation, jury, truncation and handoff are first-class events, not log lines.
Wired to
Open approval → M02-S02 · Tier → M20-S20 · Cost → M20-S16 · Agent → M18-S01.
Assumptions
Per-run token and cost budgets trigger a HANDOFF and restart at 60% context rather than truncation; checkpoints are written after each sub-agent completes.
