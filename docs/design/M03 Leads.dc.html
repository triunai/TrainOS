Purpose
Turn one inbound email into a qualified opportunity without retyping anything the agent already extracted.
Primary user
Amirah (Sales Consultant).
Components used
RecordHeader (4 metrics), section flow, AI provenance line with numbered source citations, relation list, exception banner, assistant pill.
Data contract
Enquiry{id,channel,receivedAt,from,body,status} · Extraction{topic,audience,timing,budget,confidence,sources[],agent,runId} · Organisation{id,name,matchReason} · SuggestedAction{type,payload,autonomy}
Actions & policy gates
Accept & convert (primary, creates OPP-0512 + TNA-0042), Edit first, Dismiss, Assign to me, Archive. Conversion is not policy-gated; the proposal send later is.
States rendered
Timing field shown mid-edit (Edit before use); overdue-invoice exception on the account.
AI & approval behaviour
Extraction and suggestion both carry ✦, agent name, confidence, source count and citations; autonomy is Act with approval so the human clicks.
Wired to
