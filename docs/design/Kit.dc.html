Design system & component kit
Mid-fidelity wireframe system for TrainOS. Three colours only — ink neutrals, electric blue and charcoal — on a cool graphite canvas, with status colour confined to chips. Three proof screens at the bottom render the system as real UI — M03-S01 Enquiry inbox, M02-S02 Approval detail and M04-S02 Organisation 360.

Why the state card exists
A long orchestrator run is not a list of tool calls; it is a working memory that survives restarts. The state card is that memory made visible: goal, plan with step status, decisions taken, constraints held, record pointers, open questions, and the remaining token and cost budget. When a run crosses its context budget it writes a HANDOFF and restarts carrying this card, which is why the run can be replayed from a checkpoint rather than from zero.

Placement. Right column of the trace viewer, 330px, never inside the tree. It is reference material for the person reading the trace, not part of the execution.
