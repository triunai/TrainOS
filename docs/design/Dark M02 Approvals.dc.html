▸Annotation & handoff · M02-S01
Purpose
One queue for every human decision the system needs, ordered by urgency rather than by module.
Primary user
Kelvin (Sales Manager); MD sees items above RM 50,000.
Components used
Page header, pill tab group, filter chips, data table with grouped sections, autonomy chips, AI badges, keyboard hint bar.
Data contract
ApprovalRequest{id,policyId,type,subject,valueRM,requestedBy{kind,agentId|userId},confidence,slaDueAt,autonomyLevel,status}
Actions & policy gates
Open (⏎) → M02-S02. Bulk approve is disabled while a money action is selected — money is decided one at a time.
States rendered
One SLA-breached row in danger with its checkbox disabled; one compliance item warning on a 3-day window.
AI & approval behaviour
Requester column distinguishes agent from human; confidence only shown for agent-raised items; every row carries an autonomy chip.
Wired to
Row → M02-S02 · Breaching row → discount approval · HRDC row → M12-S02 · Invoice row → M13-S02.
Assumptions
Grouping is by SLA urgency (breaching / today / this week); median decision time is a live measure from the audit log.
