▸Annotation & handoff · M01-S01
Purpose
Whole-company view for the MD: money in flight, delivery load, compliance exposure and what the agents did.
Primary user
Dato' Lim (MD); Sales Manager and Finance read it too.
Components used
Page header, MetricStrip (5 actionable cells), banner, section pattern, data table, bar chart, approval list.
Data contract
Metric{key,label,value,delta,drillTo} · AgentDaily{agent,actionsToday,autonomy,costMonthRM,evalScore} · ApprovalRequest{id,type,subject,valueRM,slaRemaining,severity}
Actions & policy gates
Every metric drills through to a filtered list. Open approvals is the only primary. No money moves here.
States rendered
AR overdue carries a warning delta and a banner; one approval row is SLA-breached in danger.
AI & approval behaviour
Agent activity and autonomy mix are reporting surfaces, not generated content, so no ✦; approval rows inherit the agent badge in M02-S01.
Wired to
Metrics → filtered lists · Approvals → M02-S01 · Agent registry → M18-S01 · AR banner → M13-S05.
Assumptions
Admin hours saved = agent actions × role-weighted manual minutes, shown as an estimate. MD sidebar variant shows Home, Sales, Relationships, Finance, Automation, Reports.
